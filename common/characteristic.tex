%Память выполняет ключевую функцию в процессах когнитивного восприятия, обучения и логического мышления. В рамках обсуждения её можно представить как систему хранения данных с двумя основными функциями: \textit{Запись}, обновляющая данные на основе поступающей извне информации, и \textit{Чтение}, обеспечивающее доступ к сохранённой информации. Данная диссертация посвящена методам использования механизма памяти в нейросетевых архитектурах. 

Память имеет ключевое значение в моделях для решения задач машинного обучения. Она является необходимым компонентом для обучения моделей и сохранения информации об обучающей выборке. Начиная с ранних работ~\cite{elman1990finding, lstm1999hochreiter}, разрабатываются архитектуры моделей с дополнительной памятью, способствующей решению задач, требующих обработки последовательностей и поиска долгосрочных зависимостей.  

Модели, основанные на архитектуре Трансформер~\cite{vaswani2017attention} получили широкое распространение в области обработки естественного языка и показывают высокую эффективность при решении задач из различных областей. Механизм внимания позволяет эффективно аггрегировать информацию из последовательности для получения контекстно-зависимых представлений. Однако применение Трансформеров к длинным текстом ограничено в связи с квадратичным ростом числа операций при увеличении длины последовательности. Исследования также показывают, что присутствуют также и другие ограничения, связанные с низким качеством решения задач с большим контекстом~\cite{liu2023lost, kuratov2024babilong} и недостатками промежуточных представлений, в которых смешивается локальная и глобальная информация~\cite{burtsev2020memory-transformer}. 

\textbf{Проблема} настоящего исследования состоит в том, чтобы исследовать и разработать архитектуры моделей, способных преодолеть существующие ограничения Трансформера, в том числе при обработке большого объема информации.

В связи с указанными ограничениями предлагаются модификации архитектуры Трансформер для снижения вычислительных затрат при обработке длинных последовательностей~\cite{katharopoulos2020transformers,dai2019transformerxl,beltagy2020longformer,zaheer2020big}. Также разрабатываются архитектуры с дополнительной памятью~\cite{burtsev2020memory-transformer} и другими модификациями~\cite{dehghani2018universal-transformer} для повышения эффективности Трансформера при решении сложных задач. Для задач, требующих интенсивного использования специфичных знаний, предлагаются архитектуры с механизмом поиска по структурированным~\cite{yu2022generate} и неструктурированным~\cite{wu2022memorizing} источникам данных.


{\aim} данной работы является исследование использования памяти в нейросетевых архитектурах и разработка модификаций Трансформера с механизмом памяти для повышения качества решения задач с большим контекстом.


Для~достижения поставленной цели необходимо было решить следующие {\tasks}:
\begin{enumerate}[beginpenalty=10000] % https://tex.stackexchange.com/a/476052/104425
    \item Предложить унифицированную нотацию для нейросетевых архитектур с фокусом на использование памяти.
    \item Предложить модификацию для архитектуры Трансформер для работы с длинными последовательностями.
    \item Разработать метод обучения предложенной архитектуры, в том числе с использованием предварительно обученных трансформерных моделей.
    \item Составить набор данных и провести валидацию языковых моделей на задачах с большим контекстом
    \item Разработать и опубликовать в открытом доступе программный комплекс для обучения предложенной архитектуры и валидации на предложенном бенчмарке.
    \item Исследовать эффективность полученных моделей на задачах моделирования языка и вопросно-ответных задачах на длинных последовательностях.
\end{enumerate}


{\novelty}
\begin{enumerate}[beginpenalty=10000] % https://tex.stackexchange.com/a/476052/104425
  \item Была предложена оригинальная архитектура рекуррентного Трансформера с памятью для обработки задач с большим контекстом.
  \item Для предложенной архитектуры был разработан и впервые применен метод обучения с расписанием для повышения способности к обобщению на большие длины задач.
  \item Впервые на момент выхода работы~\cite{bulatov2023scaling} нейросетевой моделью была достигнута длина корректно решенной задачи данного вида в 2 миллиона токенов.
  \item Был разработан оригинальный бенчмарк для оценки языковых моделей на задачах с большим контекстом.
\end{enumerate}

\textbf{Теоретическая значимость.} диссертационной работы заключается в следующих положениях:
\begin{enumerate}
  \item Предложена архитектура рекуррентного Трансформера с памятью для обработки больших контекстов.
  \item Предложен метод обучения с расписанием для повышения обобщающей способности модели к другим длинам последовательностей.
\end{enumerate}

К практической значимости относятся следующие положения.
\begin{enumerate}
  \item Предложенная архитектура позволяет увеличить контекст Трансформерной модели с линейным ростом по длине последовательности затрат при обучении и константным при последующем применении.
  \item С помощью предложенного метода обучения достигнута способность к обобщению с задач длиной порядка $10^4$ до $10^7$ токенов.
  \item Установлено новое максимальное значение длины контекста в задаче, решенной нейросетевой моделью.
  \item Модели, обученные в рамках данной работы, выложены в открытый доступ и могут использоваться для решения задач с большим контекстом. 
  \item Экспериментально показаны ограничения современных больших языковых моделей на больших контекстах на предложенном бенчмарке.
  \item Код для обучения, веса обученных моделей и разработанные в рамках диссертационной работы наборы данных выложены в открытый доступ на платформах GitHub и Hugging Face.
\end{enumerate}

{\methods} Для исследования задач, рассматриваемых в диссертации, была применена методология численного эксперимента, методы теории вероятностей, теории нейронных сетей и машинного обучения. В ходе работы была применена методология численного эксперимента для исследования рассматриваемых в диссертации задач, применены методы теории вероятностей, машинного обучения и теории нейронных сетей. Также применялись методы разработки приложений на языках Python и Bash, и фреймворки для машинного обучения PyTorch и Hugging Face transformers.
