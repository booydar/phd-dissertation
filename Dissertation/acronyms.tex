\textbf{ARMT} Associative Recurrent Memory Transformer, ассоциативный рекуррентный Трансформер с памятью

\textbf{BPTT} Backpropagation Through Time, вариант обучения методом обратного распространения ошибки, при котором градиент распространяется между временными шагами

\textbf{BPB} Bits Per Byte, метрика, для оценки языковых моделей, равная среднему числу бит, необходимых для кодирования одного байта текста.

\textbf{BABILong} \textbf{B}enchmark for \textbf{A}rtificial \textbf{I}ntelligence for \textbf{Long}-context evaluation, бенчмарк для оценки систем искусственного интелекта на задачах с большим контекстом

\textbf{GPU} Graphics Processing Unit, графический процессор

\textbf{LM} Language Modeling or Language Moded, языковое моделирование, языковая модель

\textbf{LLM} Large Language Model, большая языковая модель

\textbf{LN} Layer Normalization, нормировка по слою 

\textbf{MTL} Multiple-Task Learning, обучение на нескольких задачах

\textbf{PPL} Perplexity, перплексия

\textbf{RAG} Retrieval-Augmented Generation, генерация с использованием механизма поиска

\textbf{RMT} Recurrent Memory Transformer, рекуррентный Трансформер с памятью

\textbf{RNN} Recurrent Neural Network, рекуррентная нейронная сеть

\textbf{STL} Single-Task Learning, обучение на одной задаче

\textbf{Tr-XL} сокращение от названия модели Transformer-XL 

\textbf{QA} Question Answering, задача ответа на вопрос
